CURRENT PROJECT / AI COLLABORATION

MDS

Multimodal Data Sender

ChatGPT·Codex와 협업 개발 중

여러 종류의 데이터를
하나의 시나리오로 편집하고 송신하는 도구.

영상·음성·이미지 등의 데이터를 시간축에 배치하고, 미리보기와 사전 검사를 거쳐 실행할 수 있도록 개발하고 있습니다.

해결할 문제
여러 데이터의 실행 순서와 시점을 편집하고, 실행 전 오류와 실행 후 상태를 확인해야 합니다.
주요 기능
시나리오 편집·저장, 데이터 미리보기, 입력·시간 구간 사전 검사, 시나리오 기반 송신과 실행 기록 확인
개발 방식
요구사항과 동작을 구체화하고, ChatGPT·Codex의 구현 결과를 확인하며 오류와 사용 흐름을 개선합니다.
교육과의 연결
AI에게 작업을 설명하고, 결과를 직접 확인하며 다음 수정으로 이어가는 개발 과정을 소개할 수 있습니다.

미리보기·실제 송신·수신 결과 확인은 서로 다른 단계로 구분합니다. 이 페이지에는 일반적인 기능만 소개합니다.
