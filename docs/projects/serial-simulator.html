RS232 통신 모의 프로그램

Python·PyQt로 장비 연동 시험을 위한 통신 모의 프로그램을 개발했습니다. 통신 설정부터 송수신과 로그 확인까지의 흐름을 설계했습니다.

  • Python
  • PyQt5
  • MVVM
  • pyserial
  • SQLite
역할
UX/UI · 소프트웨어 구조 설계 · 통신·데이터 처리 · 오류 분석
상태
개발 · 저작권 등록 완료
핵심 작업
화면·통신·데이터를 연결한 데스크톱 도구

해결할 문제

장비 통신을 설정하고 데이터를 보내고 받는 과정에서, 입력·연결 상태·실행 결과를 함께 확인할 도구가 필요했습니다. 사용자의 조작과 통신 결과를 한 데스크톱 프로그램으로 연결했습니다.

본인 역할

UX/UI와 소프트웨어 아키텍처를 설계하고 통신·데이터 처리를 구현했습니다. 활동·시퀀스·클래스 다이어그램과 발표 자료를 준비해 설계 선택과 동작 흐름을 설명했습니다.

설계 선택

MVVM과 계층화한 Model을 적용했습니다. Dispatcher는 비동기 통신을, Repository·DAO는 SQLite 데이터 접근을 담당하도록 구성했습니다. 로그 창은 분리·재결합할 수 있도록 모듈화했습니다.

통신과 오류 분석

pyserial의 포트 열기·닫기와 읽기·쓰기 동작을 확인했습니다. 로그로 송수신·프레임 처리·재시도·ACK 수신 흐름을 추적하고, 포트 핸들 오류와 중복 ACK 발생 시점을 분석했습니다.

결과와 산출물

「RS232 통신 모의 프로그램」 저작권 등록 완료.

내부 코드와 통신 규격은 공개하지 않습니다.
