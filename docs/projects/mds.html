MDS · Multimodal Data Sender

영상·음성·이미지를 시간축에 배치하고 시나리오에 따라 송신하는 도구입니다. ChatGPT·Codex와 협업해 개발하고 있습니다.

  • 시나리오 편집
  • 데이터 송신
  • ChatGPT
  • Codex
역할
요구사항 구체화 · AI 구현 결과 확인 · 오류·사용 흐름 개선
상태
개발 중
핵심 작업
시나리오 편집부터 데이터 송신·확인까지

해결할 문제

여러 데이터의 실행 순서와 시점을 하나의 시나리오로 편집하고, 실행 전에 입력 오류를 확인할 필요가 있었습니다. 실행 후에는 어떤 작업을 수행했는지 기록을 확인하는 흐름도 필요했습니다.

본인 역할

요구사항과 기대 동작을 구체화하고 ChatGPT·Codex와 함께 구현했습니다. AI가 만든 결과를 직접 확인하고 오류와 사용 흐름을 정리해 다음 수정으로 이어갔습니다.

기능 구성

시간축 기반 시나리오 편집·저장, 데이터 미리보기, 입력·시간 구간 사전 검사, 시나리오 기반 송신과 실행 기록 확인을 연결했습니다.

확인하는 방식

편집한 시나리오의 미리보기, 실제 송신, 수신 결과 확인을 구분해 동작을 살폈습니다. 화면에서 기대한 결과와 실행 과정의 상태를 단계별로 확인하는 방식으로 개선하고 있습니다.

결과와 산출물

요구 설명 → AI와 구현 → 실행 결과 확인·수정으로 이어지는 개발 경험.

MDS 이름과 일반 기능만 소개하며 내부 코드·화면·연동 사양은 공개하지 않습니다.
