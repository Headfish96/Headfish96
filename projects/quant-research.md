# 퀀트 백테스트 연구

## 연구 목적

리밸런싱과 동적 자산배분 아이디어를 Python 코드로 구현하고, 수익뿐 아니라 위험·비용·실행 조건을 함께 비교하는 개인 연구입니다.
전략의 높은 과거 수익을 강조하기보다, 결과가 어떤 가정에서 나왔는지 확인하는 데 초점을 두고 있습니다.

## 작업 범위

- 전략 계산과 신호 생성, 가격 데이터 처리, 실행 계산을 모듈로 분리하는 작업
- 정기 납입이 있는 계좌에서 외부 현금흐름과 전략 수익을 구분하는 TWR 계산 연구
- 거래비용·슬리피지·신호 지연·리밸런싱 주기에 따른 결과 비교
- 실제 ETF 자료와 상장 이전 구간의 합성 자료를 구분하는 검증
- 구간별 비교와 파라미터 민감도, 미래정보 참조 가능성을 점검하는 작업

**기술:** Python, pandas, NumPy, 백테스트 스크립트와 결과 보고서.

## 공개 범위와 검증 상태

이 페이지는 로컬 연구 코드와 문서를 바탕으로 정리한 소개입니다.
전체 전략 코드를 독립 감사하거나 모든 실험을 재실행한 상태는 아니므로, 무편향·수익성·실전 자동매매 완성을 주장하지 않습니다.
백테스트 결과를 실거래 성과로 표시하지 않습니다.

개인 재무자료, 증권 계좌·인증정보, 재배포 권한을 확인하지 않은 시세 자료와 참고문헌 원문은 공개하지 않습니다.
검토를 마친 코드와 재현 가능한 데이터 획득 절차를 분리한 뒤 코드 공개 범위를 확장할 예정입니다.

이 프로젝트는 개발·연구 경험 소개이며 투자 권유나 미래 수익 보장이 아닙니다.
